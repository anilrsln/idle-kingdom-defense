# Idle Kingdom Defense

An incremental/idle tower defense game built with Phaser 3 + Vite.

## 🎮 Play Now

**[Play on GitHub Pages](https://anilrsln.github.io/idle-kingdom-defense/)**

### Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Features

- **3 Defender types:** Laser Monument (continuous beam), Archer (projectile), Cannon (AoE blast)
- **5 Enemy types:** Skeleton, Armored, Fast Runner, Food Carrier, Elite
- **Upgrade system:** Damage, Fire Rate, Range upgrades for each defender
- **Conquest Map:** Skill tree with 9 nodes for permanent bonuses
- **Prestige system:** Reset for permanent multipliers
- **Idle earnings:** Earn resources while offline
- **Auto-save:** Progress saved to localStorage every 30 seconds

## Tech Stack

- [Phaser 3.80](https://phaser.io/) — Game framework
- [Vite 5](https://vitejs.dev/) — Build tool
- Vanilla JavaScript (ES6+ modules)
